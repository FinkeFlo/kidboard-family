# ADR-0004: Internationalization

- Status: accepted
- Date: 2026-11-22

## Context
DE and EN from day one, language from config, else browser language. Few strings,
pluralization needed ("noch 1 Mal schlafen" / "4 Mal").

## Options
1. **i18next 27 + react-i18next 18** – mature, JSON resources, ICU-like plurals via
   `Intl.PluralRules`, typed keys via module augmentation, `i18next-browser-languagedetector`.
2. Lingui 6 – compile step + macros, great extraction, more tooling.
3. Paraglide JS 3 – compiled, tree-shakable message functions; younger ecosystem.

## Decision
i18next + react-i18next with bundled resources (no HTTP backend → offline-safe), typed
keys, a unit test asserting that `de` and `en` have identical key sets, and date/time
formatting via `Intl.DateTimeFormat` / date-fns locales.

## Consequences
* Small runtime cost (~20 kB gz) accepted for simplicity.
